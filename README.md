# Roadtone 로드톤

로드톤은 이동 상황과 위치, 차 안팎의 조건에 맞춰 음악·자연의 소리·조명을 제안하고, 탑승자가 원하는 요소를 바로 바꿀 수 있는 차량용 음악 경험을 제안합니다.

## 웹 시연

`Roadtone-demo.html`을 내려받아 로컬 브라우저에서 엽니다. 외부 음원이나 서비스 로그인 없이 동작합니다.

1. **퇴근길 정체**에서 재생합니다.
2. **해안가 주차**로 바꾸면 추천 음악이 바뀝니다.
3. **자연의 소리** 탭에서 빗소리, 파도, 숲, 개울을 바로 재생합니다.
4. **사운드 콘솔**에서 조명만 직접 선택합니다. 다음 장면으로 바뀌어도 선택한 조명은 유지됩니다.
5. **문 열기**로 앱의 재생 음량이 낮아지고, 문을 닫으면 복구되는 흐름을 확인합니다.

음악 목록은 내부에서만 스크롤됩니다. 하단 재생 바가 고정되며, 콘솔은 시뮬레이션에서 주차 상태일 때 열 수 있습니다.

## Android 소스 및 실행

`Roadtone-Pleos-preview.zip`을 풀고 Android Studio에서 프로젝트 폴더를 엽니다. JDK 17, Gradle 8.9, Android SDK Platform 35 및 Build Tools 34.0.0 환경에서 사용하도록 구성했습니다. GitHub Actions의 **Build release APK**를 실행하면 검증용 서명 APK를 아티팩트로 생성합니다. 제출용 설치 파일의 저장 경로는 `apk/Roadtone_Roadtone_release.apk`입니다.

## 테스트 범위

- 확인 환경은 macOS Aside의 넓은 가로 브라우저 창입니다. 음악 목록 내부 스크롤, 한 번에 여는 콘솔, 자연음 재생, 항목별 자동·직접 선택, 문 상태에 따른 앱 음량 저하를 확인했습니다.
- 목표 환경은 **Pleos Connect Emulator 2.1.0 · Connect-W**입니다. 공식 에뮬레이터의 해상도와 분할 창 검증은 아직 수행하지 않았습니다.
- Android 프로젝트는 웹 데모를 패키징한 UI 시연용입니다. 차량 상태, 무드등, 좌석과 글라스루프는 시뮬레이션입니다. 실제 차량 데이터, 스트리밍 계정, Pleos 오디오 포커스나 주행 제한 API는 연결되지 않았습니다.
